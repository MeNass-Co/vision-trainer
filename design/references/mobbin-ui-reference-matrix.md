# Mobbin UI Reference Matrix

Principle: transpose geometry, hierarchy, material, and interaction grammar. Do not clone proprietary composition, wording, iconography, imagery, or brand color.

Vision Trainer harmony rule: Apple TV material discipline, Oura restraint, Bevel/WHOOP dashboard density, Opal transitions, Endel paywall calm, Instrument Cyan throughout.
