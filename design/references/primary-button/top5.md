# Primary CTA button — top 5 Mobbin references

Element: full-width pill CTA on dark ground (e.g. "Start session"). Current execution (`design/captures/current/today.png`) is a flat cyan pill with no light model — the gap to close is a real gradient ramp / inner highlight / glow, ideally with a visible pressed or disabled sibling.

## 1. Opal — First Gem reveal, "Continue" (score 27/30)
- Mobbin URL: https://mobbin.com/screens/fc9807e4-0bc4-45dc-a8ef-ec3ac22c16a5
- Screenshot: saved as design/references/primary-button/candidate-1.png
- Convergence: 4 — gradient-fill pill CTA on a black/near-black ground is a recurring "premium fill" pattern across wellness/habit apps (echoed here by Me+, GO Club, Hypelist, all also shortlisted); Opal's specific diagonal mint→cyan ramp is a distinctive but on-pattern execution.
- Tier: 4 — Opal is a design-forward, award-adjacent digital-wellbeing app; not quite Apple/Headspace benchmark class but close.
- Invisibles ×2: 5 — true diagonal gradient ramp (mint to cyan), a genuine stadium radius, crisp dark-on-light label contrast, and an ambient colour-matched glow bleeding from the gem above into the button zone — a real light model, not a flat fill.
- Adaptability: 5 — full width, near-black ground, zero structural clutter (no avatar/search/promo), and the gradient hue family is already cyan-adjacent — near-zero-cost remap to our `ACCENT_CORE #5BE9EC` / `ACCENT #33D2D6` ladder.
- Measurability: 4 — full-res, uncropped, button fully visible; only one state shown (no pressed/disabled sibling).
- One-line why: the diagonal gradient + ambient glow is the exact "premium fill" our flat cyan pill is missing, and it's already in our hue family.

## 2. Me+ — "Hold to quit" quit-confirmation, pill CTA (score 24/30)

- Screenshot: saved as design/references/primary-button/candidate-3.png
- Convergence: 3 — vertical light-to-dark gradient pill on pure black is a common "premium fill" pattern in habit-tracking apps (Me+, Fabulous-class).
- Tier: 3 — solid, well-produced mid-tier habit app.
- Invisibles ×2: 4 — clean vertical gradient (lighter violet top → deeper violet bottom) reads as a genuine top-lit light source, crisp stadium radius, bold centered label; no pressed/disabled state visible.
- Adaptability: 5 — background is pure near-black, matching our canvas almost exactly; full width; no structural clutter; gradient direction ports directly onto our cyan ladder.
- Measurability: 5 — full-res, uncropped, single clean state, button fully legible.
- One-line why: proves a simple top-lit vertical gradient alone (no glow needed) already reads as premium on a near-black ground identical to ours.

## 4. GO Club — "What's your primary goal?", disabled "Next" (score 22/30)

- Screenshot: saved as design/references/primary-button/candidate-4.png
- Convergence: 3 — dimming/translucency (not just a flat grey swap) for the disabled state of an otherwise-identical pill is a widely-converged system pattern (iOS system buttons and most onboarding flows).
- Tier: 2 — same app as #3.

- Adaptability: 4 — same reasoning as its enabled sibling; ports cleanly to our dark canvas.
- Measurability: 5 — fully visible, uncropped; specifically valuable paired with candidate-2 as a genuine enabled/disabled sibling pair of the same component.
- One-line why: this is the enabled/disabled PAIR with #3 — exactly the kind of real disabled-sibling reference the brief asked for, useful for building `PrimaryButton`'s disabled state honestly instead of guessing.
