## 1. Tesla — Order History empty state (score 27/30)
- Mobbin URL: https://mobbin.com/screens/26cc8318-7a7c-4107-baf1-f7d464bc2a69
- Screenshot: saved as design/references/empty-state/candidate-1.png
- Convergence: 4 — same illustration/icon → title → caption → single full-width CTA stack seen in Xbox, Shake Shack, Reddit, Twitch (5/5 apps surveyed converge on this exact rhythm)
- Tier: 5 — Tesla's app is a design-benchmark digital product (Apple-tier restraint, no template chrome)
- Invisibles ×2: 8 — monochrome line icon optically centered, title/caption weight contrast is exact (bold white → medium grey), full-bleed-inset CTA with correct corner radius, no wasted ornament; the whole block reads as one measured unit
- Adaptability: 5 — icon is pure white line art, trivially remaps to lunar cyan with zero identity conflict; already dark-only; no avatars/search/promo baggage
- Measurability: 5 — 1179×2556 native, element fully uncropped, generous surrounding negative space makes every gap independently measurable
- One-line why: the tightest, most legible illustration→title→caption→CTA block of the set — nothing decorative, every gap reads as an intentional pt value.

## 5. Twitch — Following empty state (score 22/30)
- Mobbin URL: https://mobbin.com/screens/4595d310-71ad-4e6d-b9c4-fce1604e4ab8
- Screenshot: saved as design/references/empty-state/candidate-5.png
- Convergence: 4 — same stack pattern, confirms it as a cross-category (streaming) convention
- Tier: 4 — major streaming platform, solid but not top-of-list design benchmark
- Invisibles ×2: 6 — glossy 3D icon is well-rendered, but the copy block breaks the "single caption line" discipline (two separate sentences stacked with a gap between them) and the CTA is a snug-fit rectangle rather than full-width, weakening the vertical-rhythm read

- Measurability: 5 — 1179×2556 native, fully uncropped
- One-line why: useful negative example — shows what happens to the rhythm when the caption is allowed to run two sentences and the CTA loses full width; a caution, not a target.
